# Whisk app icon assets

Whisk icon concept: a kitchen whisk combined with a microphone.

- `whisk-512.png`: primary desktop icon (square RGB PNG)
- `whisk-256.png`, `whisk-128.png`, `whisk-64.png`, `whisk-32.png`: size variants
- `whisk.ico`: Windows application icon
- `whisk.icns`: macOS icon, if included

This is an initial visual concept extracted from the brand concept image and resized; the icon is a raster asset, not an editable SVG. Final platform-specific asset pipeline and trademark clearance remain to be completed.
